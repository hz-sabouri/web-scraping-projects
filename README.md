# Web Scraping Projects

A collection of Python web scrapers built between **January and February 2026**.

| Project | What it does |
|---|---|
| [sistani](sistani/) | Collects the Persian books and Q&A section of sistani.org into structured JSON records |
| [codeyad](codeyad/) | Reads a paginated course-listing JSON API into CSV and downloads the course images |

Each folder is self-contained, with its own README and `requirements.txt`.

## Other scrapers

I also built scrapers for Divar (car listings from four cities) and Digikala
(about 2,000 products with specifications), both storing data in SQLite.
Their code is not included here because the target sites have since changed
their structure and the scripts no longer work.

## Note on data

Only the scraper code is published here. Scraped data is not included: it belongs to the original publishers, and it can be regenerated by running the scripts.
